Password-Free SSH Login (Ubuntu → Raspberry Pi)

This procedure configures password-free SSH login from an Ubuntu workstation to a Raspberry Pi while still allowing normal password login as a fallback.
1. Check for an existing SSH key
ls ~/.ssh
If id_ed25519 and id_ed25519.pub already exist, proceed to step 3.

2. Generate a new SSH key
ssh-keygen -t ed25519
Press Enter to accept the default filename.
The generated files are:
~/.ssh/id_ed25519
~/.ssh/id_ed25519.pub

3. Copy the public key to the Raspberry Pi
ssh-copy-id pi@192.168.43.218
Enter the Raspberry Pi password once.
The public key is copied to:
/home/pi/.ssh/authorized_keys

4. Test password-free login
ssh pi@192.168.43.218
The login should succeed without requesting a password.

5. Verify the SSH server configuration (Raspberry Pi)
Edit the SSH configuration:
sudo nano /etc/ssh/sshd_config
Ensure the following options are present:
PubkeyAuthentication yes
PasswordAuthentication yes
PermitRootLogin no
Restart the SSH server:
sudo systemctl restart ssh

6. Verify the active SSH configuration
sudo sshd -T | grep -E 'pubkeyauthentication|passwordauthentication'
Expected output:
pubkeyauthentication yes
passwordauthentication yes

7. Troubleshooting
Verbose SSH output:
ssh -v pi@192.168.43.218
Common problems:
    • Using sudo ssh instead of ssh.
    • Missing or incorrect permissions on ~/.ssh or authorized_keys.
    • PasswordAuthentication or PubkeyAuthentication disabled in sshd_config.

Notes
    • Always use ssh, not sudo ssh.
